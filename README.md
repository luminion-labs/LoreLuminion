# LoreLuminion

**Illuminating Every Story.**

A responsive editorial entertainment-culture website covering gaming, anime & manga, movies & TV, technology, and internet culture.

## Stack
- Next.js 15 / React 19
- TypeScript
- Three.js ambient starfield
- Custom responsive CSS
- Vercel deployment-ready

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import this repository into Vercel. The project uses the standard Next.js build command.

## Notes
- The homepage currently uses sample editorial cards, not live or verified news.
- The logo in `public/logo.png` is the user-provided image.
- Three.js effects are decorative and should never be required to navigate the site.
